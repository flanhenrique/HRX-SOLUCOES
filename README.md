# HRX Solutions

Site institucional da **HRX Solutions**, desenvolvido inicialmente no GitHub e preparado para publicação via GitHub Pages.

## Direção do projeto

A HRX é apresentada como uma empresa de soluções que combina **organização, tecnologia, documentação, operações e estratégia** para transformar necessidades reais em entregas concretas.

Projetos em destaque:

- **VOLT** — acompanhamento e inteligência de consumo de energia e água.
- **NEXUS** — gestão comercial e operacional.
- **SOMMA** — consultoria, gestão e relacionamento para hospitalidade e condomínios.

## Stack

- React
- TypeScript
- Vite
- CSS responsivo próprio
- GitHub Actions / GitHub Pages

## Desenvolvimento local

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```
