# Documentos — HRX Solutions

Área documental vinculada ao repositório institucional da HRX Solutions.

## Estrutura

- `00_INSTITUCIONAL/` — documentos e materiais da própria HRX.
- `01_CLIENTES/` — documentação organizada por cliente.
- `02_MODELOS/` — modelos reutilizáveis.
- `03_PROJETOS_INTERNOS/` — documentação de projetos internos.
- `04_COMERCIAL/` — propostas, apresentações e materiais comerciais.
- `05_FINANCEIRO/` — notas, comprovantes e controles.
- `06_JURIDICO/` — contratos, termos e registros.
- `99_ARQUIVO/` — documentos descontinuados ou históricos.

## Padrão de nome de arquivo

`AAAA-MM-DD_CLIENTE_TIPO_DESCRICAO_V01.ext`

Exemplo: `2026-08-17_HORTIFRUTI-REVOLUCAO_CHECKLIST-INFORMACOES_V01.pdf`

> Este repositório é público. Não armazenar senhas, tokens, chaves de API ou outras credenciais.
